# Crypto Miner Idle（仮想通貨マイニング放置ゲーム）

## ゲームのタイトルと概要

**Crypto Miner Idle** は、仮想通貨のマイニングをテーマにしたブラウザ向け放置系インクリメンタルゲームです。

古いノートPCでの手動ハッシュ計算（クリック）から始まり、ゲーミングGPU、ASICマイナー、量子ブロックチェーン炉といった8種類のマイニング設備や各種アップグレードを購入して **クリプトコイン（Coin）** を採掘します。  
採掘が進むと **ハードフォーク（プレステージ／転生）** を実行でき、進行状況をリセットする代わりに永続通貨 **ジェネシスブロック（GB）** を獲得して、次の周回をさらに加速させることができます。

---

## 遊び方（操作方法）

### 起動方法
ビルドツールやローカルサーバーは不要です。`index.html` をブラウザで直接開くだけでプレイできます。

### 基本操作
1. **手動マイニング**: 画面左側の **「MINE HASH」** ボタンをクリックして COIN を採掘します。
2. **設備の購入**: 右側の **「設備」** タブからマイニング設備を購入し、秒間採掘量（CPS）を増やします。購入数量は `x1` / `x10` / `x100` / `Max` で切り替え可能です。
3. **強化の購入**: **「強化」** タブからクリック効率や設備の倍率を上げるアップグレードを購入します（「すべて購入」ボタンで一括購入も可能）。
4. **ハードフォーク（転生）**: 今回の周回累計採掘量が `1.00 M Coin` 以上になると、左下の **「ハードフォークを実行」** ボタンが有効になります。実行すると所持 COIN・設備・通常強化がリセットされ、ジェネシスブロック（GB）を獲得します。
5. **永続強化・オートバイヤー**: **「フォーク」** タブで GB を消費して永続ボーナス（アルゴリズム最適化、バルク購入契約、プレマイニング資金、自動投資ボットなど）を強化できます。
6. **実績**: **「実績」** タブで達成状況を確認できます。実績を1つ解除するごとに全採掘量が `+2%` 増加します。
7. **設定・保存・表記切替**:
   - ヘッダーの **「表記」** ボタンで数値表記（接尾辞 `K/M/B/T...` ⇄ 科学的記数法）を切り替えられます。
   - **「設定 / 保存」** から手動セーブ、Base64 文字列によるデータ書き出し／読み込み、データ完全初期化が行えます（15秒ごとに自動保存され、次回起動時には最大24時間・効率80%のオフライン採掘報酬を受け取れます）。
8. **隠しコマンド（チートコンソール）**:
   - キーボードでコナミコマンド（`↑ ↑ ↓ ↓ ← → ← → B A`）を入力すると、**チートコンソール**が開き、所持 COIN と GB の個数を自由に変更できます。

## 工夫した点

コミット履歴（`d7e1664` 〜 `13fbf55`）に基づき、以下の点を工夫しています。

- **ビルド不要で完結するモジュール分割構成（`d7e1664`）**  
  フレームワークやバンドラーを使わず、役割ごとに JavaScript ファイルを分割（`data.js` / `format.js` / `engine.js` / `storage.js` / `ui.js` / `main.js`）し、`index.html` から `<script defer>` で依存順に読み込む構成としました。これにより `file://` プロトコルで直接開いてもそのまま動作します。
- **描画負荷とクリック操作性の両立（`d7e1664`）**  
  100ms 間隔のメインループでは `UI.updateDynamicUI()` により数値・プログレスバー・ボタンの有効状態のみを軽量更新し、リスト全体の DOM 再生成は設備解放・購入・タブ切り替え時のみに限定することで、連打やボタン操作が途切れないようにしました。
- **UTF-8 対応のセーブデータ管理とオフライン進行（`d7e1664`）**  
  `localStorage` への自動保存に加え、`TextEncoder` / `TextDecoder` を用いた日本語安全な Base64 エクスポート／インポート機能と、経過時間に応じたオフライン採掘報酬計算を実装しました。
- **コナミコマンド入力の使いやすさへの配慮（`13fbf55`）**  
  `input` や `textarea` にフォーカスしている間はコマンド判定をスキップし、さらに `↑` キーを3回以上連続入力した場合でも2回入力済み状態を維持してコマンドを成立させられるようにしています。

## 作りながら変えた点

- **技術スタックとテーマの整理（`d7e1664`）**  
  初期構想段階の汎用エネルギー開拓テーマ・ビルド環境前提の構成から、仮想通貨マイニングテーマ（「クリプトコイン」「ハードフォーク」「ジェネシスブロック」）と、HTML / CSS / Vanilla JavaScript の個別ファイル分割構成へ変更して実装しました。
- **チートコンソール機能の後付け追加（`13fbf55`）**  
  基本ゲームループ・ショップ・ハードフォーク・セーブ機能一式を実装して初回コミット（`d7e1664`）を完了した後、後半のバランスやハードフォークの挙動をいつでも手軽に試せるよう、コナミコマンドで起動するチートコンソール画面（直接数値入力および `+1M / +1B / +1T Coin`・`+10 / +100 / +1,000 GB` のクイック加算ボタン）を追加しました。
